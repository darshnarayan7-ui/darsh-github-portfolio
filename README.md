# Darsh Narain Srivastava — Portfolio

A resume-first personal portfolio with a Spider-Noir inspired visual system: deep charcoal, crimson geometry, editorial typography, grain texture, parallax tilt, glitch reveal, and scroll-triggered motion.

## Included

- Responsive single-page resume layout
- Projects, experience, education, skills, achievements, and contact sections
- Click-triggered hero glitch interaction
- Cursor-based parallax tilt on the hero artwork
- IntersectionObserver-powered scroll reveal animations
- Mobile navigation and reduced-motion accessibility support
- Downloadable resume PDF

## Development

```bash
pnpm install
pnpm dev
```

The site is built with React, TypeScript, Vite, Tailwind CSS, and Lucide icons.

## Personalization

Update the content arrays in `client/src/pages/Home.tsx`, replace the hero artwork storage path, and update the GitHub / LinkedIn URLs before deploying to your preferred host.
